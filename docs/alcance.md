# Alcance futuro del sistema

Una versión futura del Catálogo de Recursos Académicos podría incluir:

1. Registro de nuevos recursos (libros, videos, artículos, sitios web, software) con metadatos completos.
2. Búsqueda y filtrado de recursos por tipo, tema, nivel o autor.
3. Recomendación de recursos relacionados según el tema consultado.
4. Exportación del catálogo a distintos formatos (CSV, PDF) para compartirlo.
